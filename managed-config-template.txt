KioskPlayer Managed Config Template

Use this with any MDM that supports Android Managed Config / App Restrictions.

Key: path
Type: string
Allowed: valid directory path
Examples:
- /storage/emulated/0/Download/kiosk
- Movies

Key: mode
Type: string (choice)
Allowed values:
- single
- playlist

Key: files
Type: string
Format: comma-separated file names or absolute file paths
Examples:
- intro.mp4
- intro.mp4,promo.mov
- /storage/emulated/0/Download/kiosk/intro.mp4,/storage/emulated/0/Download/kiosk/promo.mov

Key: loop
Type: string (choice)
Allowed values:
- one
- all
- off

Key: stream_url
Type: string
Allowed: valid stream URL (HLS/MP4)
Example:
- https://example.com/live.m3u8

Key: source_preference
Type: string (choice)
Allowed values:
- local_first
- stream_first
- local_only
- stream_only

Key: fallback_on_stream_error
Type: boolean
Allowed values: true, false

Key: image_duration_sec
Type: integer
Allowed range: 1 to 3600

Key: schedule_enabled
Type: boolean
Allowed values: true, false

Key: schedule_start
Type: string
Format: HH:mm
Example: 09:00

Key: schedule_end
Type: string
Format: HH:mm
Example: 18:00

Key: schedule_days
Type: string
Format: comma-separated short day names or 1..7
Examples:
- mon,tue,wed,thu,fri
- 1,2,3,4,5

Key: heartbeat_sec
Type: integer
Allowed range: 15 to 3600

Key: fullscreen
Type: boolean
Allowed values: true, false

Key: controls
Type: string (choice)
Allowed values:
- show
- hide

Key: orientation
Type: string (choice)
Allowed values:
- landscape
- portrait
- auto

Key: mute
Type: boolean
Allowed values: true, false

Key: volume
Type: integer
Allowed range: 0 to 100

Key: autostart
Type: boolean
Allowed values: true, false

Key: skip_missing_files
Type: boolean
Allowed values: true, false

Key: show_debug_overlay
Type: boolean
Allowed values: true, false
