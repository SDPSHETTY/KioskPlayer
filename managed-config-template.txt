KioskPlayer Managed Config Template

Use this as a generic reference for Esper/MDM managed config.

Key: video_dir
Type: string
Allowed: Any valid directory path
Examples:
- /sdcard/Download/kiosk
- Movies

Key: play_mode
Type: string (choice)
Allowed values:
- single
- playlist

Key: single_file
Type: string
Used when play_mode=single
Example:
- intro.mp4
- /sdcard/Download/kiosk/intro.mp4

Key: playlist_files
Type: string
Used when play_mode=playlist
Format: comma-separated file names/paths
Example:
- intro.mp4,promo.mov,loop1.mp4

Key: loop_mode
Type: string (choice)
Allowed values:
- loop_one
- loop_all
- once

Key: fullscreen
Type: boolean
Allowed values: true, false

Key: hide_controls
Type: boolean
Allowed values: true, false

Key: orientation
Type: string (choice)
Allowed values:
- landscape
- portrait
- auto

Key: mute
Type: boolean
Allowed values: true, false

Key: volume_percent
Type: integer
Allowed range: 0 to 100

Key: autostart_on_boot
Type: boolean
Allowed values: true, false

Key: skip_missing_files
Type: boolean
Allowed values: true, false

Key: show_debug_overlay
Type: boolean
Allowed values: true, false
