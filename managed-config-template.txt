KioskPlayer Managed Config Template

Use this with any MDM that supports Android Managed Config / App Restrictions.

Key: path
Type: string
Allowed: valid directory path
Examples:
- /storage/emulated/0/Download/kiosk
- Movies

Key: mode
Type: string (choice)
Allowed values:
- single
- playlist

Key: files
Type: string
Format: comma-separated file names or absolute file paths
Examples:
- intro.mp4
- intro.mp4,promo.mov
- /storage/emulated/0/Download/kiosk/intro.mp4,/storage/emulated/0/Download/kiosk/promo.mov

Key: loop
Type: string (choice)
Allowed values:
- one
- all
- off

Key: fullscreen
Type: boolean
Allowed values: true, false

Key: controls
Type: string (choice)
Allowed values:
- show
- hide

Key: orientation
Type: string (choice)
Allowed values:
- landscape
- portrait
- auto

Key: mute
Type: boolean
Allowed values: true, false

Key: volume
Type: integer
Allowed range: 0 to 100

Key: autostart
Type: boolean
Allowed values: true, false

Key: skip_missing_files
Type: boolean
Allowed values: true, false

Key: show_debug_overlay
Type: boolean
Allowed values: true, false

------------------------------------------------------------
{
  "path": "/storage/emulated/0/Download/kiosk",
  "mode": "playlist",
  "files": "intro.mp4,promo.mov",
  "loop": "all",

  "controls": "hide",
  "orientation": "landscape",
  "mute": false,
  "volume": 80,
  "autostart": true,
  "show_debug_overlay": false,
  "skip_missing_files": true
}
